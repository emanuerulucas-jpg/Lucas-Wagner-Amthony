# RAS-Docker — Aplicação Flask com Docker

Projeto desenvolvido para a disciplina de **Redes e Administração de Sistemas (RASI)** do Instituto Federal de Educação, Ciência e Tecnologia de São Paulo — Campus Campos do Jordão.

O projeto apresenta a criação de uma máquina virtual com Ubuntu Server, configuração de acesso remoto via SSH e a utilização do Docker para executar uma aplicação web desenvolvida em Python com Flask.

## Objetivos

- Criar e configurar uma máquina virtual com Ubuntu Server.
- Configurar acesso remoto utilizando SSH.
- Instalar e testar o Docker.
- Criar uma aplicação web utilizando Flask.
- Criar uma imagem Docker para a aplicação.
- Executar a aplicação dentro de um container.
- Criar novas rotas para a aplicação.
- Testar o funcionamento da aplicação através do navegador.

## Tecnologias utilizadas

- Ubuntu Server 24.04.5 LTS
- VirtualBox
- SSH
- Docker
- Python
- Flask
- Dockerfile
- GitHub
